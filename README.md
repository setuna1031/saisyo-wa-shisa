# 最初はシーサー！！

小学2年生向けのサッカー練習・まねログ・クイズアプリです。

## GitHub Pages公開手順

1. GitHub Desktopで新しいリポジトリを作る
2. この `publish` フォルダ内のファイルをリポジトリへ入れる
3. `Commit to main`
4. `Publish repository`
5. GitHubのリポジトリ画面で `Settings` → `Pages`
6. `Source` を `Deploy from a branch` にする
7. Branchを `main`、フォルダを `/root` にする
8. `Save`

公開URLは次のような形になります。

```text
https://ユーザー名.github.io/リポジトリ名/
```

## 注意

- このアプリ本体は公開されます
- 練習ログは各スマホ・タブレットのブラウザ内に保存されます
- 子どもの名前、学校名、住所などの個人情報は入れないでください
